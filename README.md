# Diabites-Prediction-Risk-system
# 🩺 Diabetes Prediction Model with Explainable AI

This project is a complete Machine Learning pipeline for predicting diabetes using patient health data. The notebook includes data preprocessing, visualization, model training, evaluation, hyperparameter tuning, and Explainable AI techniques using SHAP.

The system trains and compares multiple machine learning models including Random Forest, Gradient Boosting, and Logistic Regression to identify the best-performing model based on evaluation metrics such as Accuracy, Precision, Recall, F1-Score, and ROC-AUC.

To improve transparency and interpretability, the project integrates SHAP (SHapley Additive Explanations), allowing users to understand how different features contribute to diabetes predictions. The notebook also includes a deployment-ready prediction function capable of generating human-readable explanations for predictions.

## 🔥 Features

* Data preprocessing and feature engineering
* Exploratory Data Analysis (EDA) with visualizations
* Multiple ML model training and comparison
* Hyperparameter tuning using GridSearchCV
* Performance evaluation using classification metrics
* Explainable AI with SHAP
* Deployment-ready prediction function
* Model saving using Joblib

## 🎯 Goal

The goal of this project is to build an accurate and interpretable diabetes prediction system that can assist in early detection and healthcare decision-making.
